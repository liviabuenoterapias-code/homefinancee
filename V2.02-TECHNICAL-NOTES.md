## Smart Add Item Modal

### Implementation Details

**Location:** Lines 6006-6186 in receipt-parser-v2.html

**Functions:**
- `addManualItem()` - Main entry point, builds product list and shows modal
- `showProductSuggestions()` - Displays suggestion dropdown
- `filterProductSuggestions()` - Filters products by search term
- `selectProduct(name, storeSection, avgPrice)` - Auto-fills form when product selected
- `confirmAddManualItem()` - Validates and adds item to shopping list

### Data Flow

```
User clicks "+ Add Item"
  ↓
addManualItem()
  → buildProductLibrary() - Gets all products from receipts
  → loadCustomMappings() - Gets user customizations
  → Build unique product list with stats
  → Store in window.addItemProductList
  → Render modal with search input
  ↓
User types in search box
  ↓
filterProductSuggestions() (triggered by oninput)
  → Filter window.addItemProductList by search term
  → Show top 20 matches
  → Display: name, category, price, purchase count
  ↓
User clicks product OR enters new name
  ↓
selectProduct() OR manual entry
  → Auto-fill category and price (if existing product)
  → Show confirmation message
  ↓
User clicks "Add to List"
  ↓
confirmAddManualItem()
  → Validate name exists
  → Check for duplicates
  → Create item object
  → Add to shopping list
  → Save to localStorage
  → Re-render list
```

### Key Design Decisions

**1. Use mousedown instead of click**
- Prevents blur event from hiding dropdown before click registers
- Common pattern for autocomplete UIs

**2. Store product list in window scope**
```javascript
window.addItemProductList = productList;
```
- Allows other functions to access without passing parameters
- Simplifies event handler setup

**3. Duplicate product consolidation**
```javascript
const uniqueProducts = {};
products.forEach(p => {
  if (!uniqueProducts[p.name] || uniqueProducts[p.name].purchaseCount < p.purchaseCount) {
    uniqueProducts[p.name] = p;
  }
});
```
- Multiple raw names can map to same product name
- Keep the one with highest purchase count (most representative)

**4. Escape single quotes in product names**
```javascript
onclick="selectProduct('${p.name.replace(/'/g, "\\'")}')"
```
- Prevents JavaScript syntax errors when name contains apostrophes
- Example: "McVitie's Digestive" → "McVitie\'s Digestive"

## Smarter Suggestion Algorithm

### Implementation Details

**Location:** Lines 5206-5485 in receipt-parser-v2.html

**Functions:**
- `generateSuggestions()` - Main algorithm, calculates all suggestions
- `renderSuggestions(suggestions)` - Displays suggestions with visual indicators

### Algorithm Steps

#### 1. Get Staple Products
```javascript
const stapleProducts = analysisInstance.getStapleProducts(0.5);
const top50Staples = stapleProducts.slice(0, 50);
```
- Frequency threshold: 0.5 (purchased in at least 50% of months)
- Top 50 most frequently purchased products
- Reduces noise from one-time purchases

#### 2. Build Product Groups
```javascript
const groupedProducts = {};
allReceipts.forEach(receipt => {
  receipt.items.forEach(item => {
    const standardName = window.ProductCategories.standardizeProduct(item.name);
    const productName = mapping.productName || standardName;

    if (!groupedProducts[productName]) {
      groupedProducts[productName] = {
        name, brand, productType, storeSection,
        purchases: [],
        totalSpent: 0,
        prices: []  // NEW: Track all prices for statistics
      };
    }

    groupedProducts[productName].purchases.push({
      date: new Date(receipt.date),
      price: item.totalPrice,
      quantity: item.quantity,
      unitPrice: item.totalPrice / item.quantity  // NEW
    });

    groupedProducts[productName].prices.push(unitPrice);  // NEW
  });
});
```

#### 3. Track Co-Purchases
```javascript
const itemCoBuys = {};  // productName -> {coProduct: count}

allReceipts.forEach(receipt => {
  const receiptProducts = new Set();

  // Collect all products in this receipt
  receipt.items.forEach(item => {
    const productName = getProductName(item);
    if (isStaple(productName)) {
      receiptProducts.add(productName);
    }
  });

  // Build co-purchase matrix
  const products = Array.from(receiptProducts);
  products.forEach(prod1 => {
    if (!itemCoBuys[prod1]) itemCoBuys[prod1] = {};
    products.forEach(prod2 => {
      if (prod1 !== prod2) {
        itemCoBuys[prod1][prod2] = (itemCoBuys[prod1][prod2] || 0) + 1;
      }
    });
  });
});
```

**Example Output:**
```javascript
itemCoBuys = {
  "milk": { "butter": 15, "bread": 12, "eggs": 8 },
  "butter": { "milk": 15, "bread": 10, "eggs": 8 },
  "bread": { "milk": 12, "butter": 10, "jam": 6 }
}
```

#### 4. Calculate Urgency
```javascript
// Basic frequency
const sortedDates = purchases.map(p => p.date).sort((a, b) => a - b);
const lastPurchase = sortedDates[sortedDates.length - 1];
const daysSince = Math.floor((new Date() - lastPurchase) / (1000 * 60 * 60 * 24));

let avgDaysBetween = 999;
if (purchases.length >= 2) {
  let totalDays = 0;
  for (let i = 1; i < sortedDates.length; i++) {
    totalDays += (sortedDates[i] - sortedDates[i-1]) / (1000 * 60 * 60 * 24);
  }
  avgDaysBetween = totalDays / (sortedDates.length - 1);
}

// Urgency scoring
const overdueRatio = daysSince / avgDaysBetween;
let urgency = 'low';
let urgencyScore = 0;

if (overdueRatio >= 1.5) {
  urgency = 'critical';  // 50% overdue
  urgencyScore = 3;
} else if (overdueRatio >= 1.2) {
  urgency = 'high';      // 20% overdue
  urgencyScore = 2;
} else if (overdueRatio >= 0.8) {
  urgency = 'medium';    // approaching due
  urgencyScore = 1;
}
```

**Example:**
```
Product: Milk
Last purchased: 2025-01-11
Today: 2025-01-23
Days since: 12 days

Purchase dates: [2025-01-04, 2025-01-11, 2025-01-18, ...]
Intervals: [7, 7, ...]
Average interval: 7 days

Overdue ratio: 12 / 7 = 1.71
Urgency: CRITICAL (ratio >= 1.5)
Urgency score: 3
```

#### 5. Price Statistics
```javascript
const prices = group.prices.sort((a, b) => a - b);
const minPrice = prices[0];
const maxPrice = prices[prices.length - 1];
const medianPrice = prices[Math.floor(prices.length / 2)];

// Check if recent prices are good deals
const recentPurchases = purchases.slice(-3);  // Last 3 purchases
const recentAvgPrice = recentPurchases.reduce((sum, p) => sum + p.unitPrice, 0) / recentPurchases.length;
const isGoodDeal = recentAvgPrice < medianPrice * 0.95;  // 5% below median
```

**Example:**
```
Product: Pasta 500g
All prices: [12.90, 13.50, 13.50, 13.90, 14.50, 15.00] kr
Min: 12.90 kr
Max: 15.00 kr
Median: 13.70 kr

Recent 3 purchases: [12.90, 13.50, 13.50] kr
Recent average: 13.30 kr

Good deal threshold: 13.70 × 0.95 = 13.02 kr
Is good deal: 13.30 > 13.02 → No

(If recent average was 12.80, it would be a good deal)
```

#### 6. Complementary Boost
```javascript
const currentList = loadShoppingList();
const currentListNames = new Set(currentList.map(item => item.name.toLowerCase()));

let complementaryBoost = 0;
let complementaryItems = [];

if (itemCoBuys[group.name]) {
  Object.keys(itemCoBuys[group.name]).forEach(coProd => {
    if (currentListNames.has(coProd.toLowerCase())) {
      complementaryBoost += 1;
      complementaryItems.push(coProd);
    }
  });
}

const finalUrgencyScore = urgencyScore + complementaryBoost;
```

**Example:**
```
Product: Butter
Co-buys: { "milk": 15, "eggs": 8, "bread": 10 }

Current shopping list contains:
- Milk ✓
- Bread ✓
- Coffee
- Sugar

Complementary boost: +2 (milk + bread)
Complementary items: ["Milk", "Bread"]

Base urgency score: 1 (medium)
Final urgency score: 1 + 2 = 3 (equivalent to critical)
```

#### 7. Filtering
```javascript
const shouldSuggest = urgencyScore >= 1 || complementaryBoost > 0;

if (shouldSuggest) {
  suggestions.push({
    name, brand, productType, storeSection,
    avgPrice, minPrice, maxPrice,
    isGoodDeal,
    daysSince, avgDaysBetween,
    urgency, urgencyScore: urgencyScore + complementaryBoost,
    purchaseCount, complementaryItems
  });
}
```

**Logic:**
- Suggest if urgency ≥ medium (score 1+)
- OR if complementary items exist (boost > 0)
- Skip low urgency items with no complementary relationships

#### 8. Final Filtering
```javascript
const dismissed = loadDismissedSuggestions();

const filteredSuggestions = suggestions.filter(sug => {
  const isDismissed = dismissed[sug.name.toLowerCase()];
  const isInList = currentListNames.has(sug.name.toLowerCase());
  return !isDismissed && !isInList;
});
```

#### 9. Sorting
```javascript
filteredSuggestions.sort((a, b) => {
  // Primary: urgency score (including complementary boost)
  if (b.urgencyScore !== a.urgencyScore) {
    return b.urgencyScore - a.urgencyScore;
  }
  // Secondary: days overdue
  return b.daysSince - a.daysSince;
});
```

**Sort Order:**
1. Critical items (score 3+) with complementary boost
2. Critical items (score 3) without boost
3. High items (score 2) with boost
4. High items (score 2) without boost
5. Medium items (score 1) with boost
6. Medium items (score 1) without boost

Within same score, items overdue by more days appear first.

## Performance Considerations

### Optimization Strategies

#### 1. Product List Deduplication
```javascript
// Instead of:
const productList = productLibrary.sort(...);

// Use:
const uniqueProducts = {};
products.forEach(p => {
  if (!uniqueProducts[p.name] || uniqueProducts[p.name].purchaseCount < p.purchaseCount) {
    uniqueProducts[p.name] = p;
  }
});
const productList = Object.values(uniqueProducts).sort(...);
```
**Benefit:** Reduces list size from ~500 items to ~200 unique products

#### 2. Top N Filtering
```javascript
// Only show top 20 matches
suggestionsDiv.innerHTML = filtered.slice(0, 20).map(p => `...`).join('');
```
**Benefit:** Reduces DOM size, faster rendering

#### 3. Limit Staples to Top 50
```javascript
const top50Staples = stapleProducts.slice(0, 50);
```
**Benefit:** Reduces co-purchase matrix size from O(n²) to O(50²)

#### 4. Set Lookups
```javascript
// Fast O(1) lookups
const stapleNames = new Set(top50Staples.map(s => s.name.toLowerCase()));
const currentListNames = new Set(currentList.map(item => item.name.toLowerCase()));

// Instead of O(n) array searches
if (stapleNames.has(productName.toLowerCase())) { ... }
```

#### 5. Single Pass Co-Purchase Tracking
```javascript
// Build entire co-purchase matrix in one receipt loop
allReceipts.forEach(receipt => {
  // Collect products
  // Build matrix
});
```
**Benefit:** Avoids multiple passes through receipt data

### Performance Metrics

Typical performance on 100 receipts, 200 products:
- `buildProductLibrary()`: ~50-100ms
- `generateSuggestions()`: ~100-200ms
- `renderSuggestions()`: ~20-50ms
- Total: ~200-350ms

None. v2.02 is fully backward compatible with v2.0 and v2.01.

### Data Migration
No migration needed. New fields added to suggestion objects but old code still works.

### Browser Requirements
- ES6+ support (arrow functions, template literals, Set, Map)
- localStorage API
- Flexbox CSS
- Modern event handling

**Supported:**
- Chrome 90+
- Firefox 88+
- Edge 90+
- Safari 14+
